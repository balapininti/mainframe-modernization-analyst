# Starter prompts

Developers can paste these into Copilot agent mode or Copilot CLI.

## Getting started

- Inventory this system and tell me what's missing.
- Give me the big picture and the main business flows.

## Understanding

- Explain the end-to-end flow for `<transaction or job>`.
- Explain `<program>` to a Spring Boot developer.
- Build the data dictionary for `<copybook>`.

## Specifying

- Write requirements and rules for `<slice>`.
- Write test scenarios for `<slice>`.
- Suggest a Spring Boot mapping for `<slice>`.

## Missing information

- What's still missing, and who do I ask?
- Prepare the mainframe team request and SME questions.
- Here's the answer or file for `<item>`. Update the analysis.

## Planning

- Suggest a migration order and explain why.

## About the skill

- Report a problem with this skill.
- Export the skill's logs for the maintainer.
